\section{Quick problem guide}

\begin{tabular}{>{\raggedright\arraybackslash}p{.32\textwidth}>{\raggedright\arraybackslash}p{.60\textwidth}}
\toprule
\textbf{What you see} & \textbf{What to do} \\
\midrule
\texttt{No module named telebot} & Activate the intended environment and run
\texttt{python -m pip install -r requirements.txt}. \\
\addlinespace
\texttt{BOT\_TOKEN is missing} & Set the environment variable in the same
terminal where you run \texttt{python bot.py}. \\
\addlinespace
\texttt{Unauthorized} or token error & Copy the full token again without spaces.
If it may have leaked, revoke it in BotFather first. \\
\addlinespace
Bot prints that it runs but does not reply & Press Start in Telegram, confirm the
username, keep the terminal open, and check the internet connection. \\
\addlinespace
Another polling instance error & Stop the other running copy of this bot. Only
one polling process should use the same token. \\
\bottomrule
\end{tabular}

\section{Compile this book in TeXstudio}

Open the edition's \texttt{main.tex}, choose \textbf{XeLaTeX} as the compiler,
and build twice so the table of contents is current. Do not compile a chapter
file by itself. The Persian edition requires XePersian and uses IRANSansX when
installed, with B Nazanin and Noto Naskh Arabic fallbacks configured.

Generated files such as PDF, AUX, LOG, TOC, and SyncTeX output are ignored by
Git. Keep them locally or attach a PDF to a release when you want to distribute
a built copy; do not commit repeated build products to the repository.

\section{Small next steps}

After this version works, make one change at a time: add a \texttt{/about}
command, customize the welcome text, add reply buttons, or deploy the bot on a
service that can keep Python running. Never hard-code the token during deployment.
