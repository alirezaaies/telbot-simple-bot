# مستندات فارسی

فایل `main.tex` را در TeXstudio باز کنید، موتور **XeLaTeX** را انتخاب کنید و برای به‌روزشدن فهرست مطالب دو بار خروجی بگیرید. فایل `config.tex` شامل قلم‌ها، رنگ‌ها، پیوندها، تنظیم کد و کادرهای مشترک است. شش فایل پوشهٔ `chapters/` متن آموزش را نگه می‌دارند و از `main.tex` فراخوانی می‌شوند؛ فقط `main.tex` را کامپایل کنید.

این نسخه از XePersian و جهت راست‌به‌چپ استفاده می‌کند. قلم نخست `IRANSansX` است و در نبود آن، `B Nazanin` و سپس `Noto Naskh Arabic` انتخاب می‌شوند.

خروجی PDF و فایل‌های کمکی لاتک عمداً در گیت نادیده گرفته شده‌اند. در صورت نیاز، PDF ساخته‌شده را از بخش Release گیت‌هاب منتشر کنید تا مخزن سبک بماند.
